# 🎵 VibeStream - Immersive Theater Edition

Welcome to the official update repository for **VibeStream**, a premium, full-screen audio player built with Python and CustomTkinter. Featuring dynamic Avee-style circular visualizers, custom theme engines, and real-time synchronized lyrics syncing.

---

## 🛠️ Main Features
* **Immersive Visualizer:** 75-bar responsive radial audio visualizer with adjustable bass boost.
* **Smart Lyrics Fetcher:** Cleans messy file names automatically to track down lyrics online via global APIs.
* **Hybrid Sync:** Supports offline `.lrc` files, manual `.txt` loading, and real-time line highlighting.
* **Persistent Settings:** Auto-saves your preferred custom wallpaper directories and folder paths seamlessly.
